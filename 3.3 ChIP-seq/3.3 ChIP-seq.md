### 1. 请解释在ChIP-seq实验中为什么一般都要平行做一个 control （通常叫 input）的实验。
- Input 是将染色质超声打断后，不经过任何抗体免疫沉淀，直接纯化、建库并测序的样品。它代表了样本在抗体富集步骤前的总 DNA 组成。
- 由于基因组并非完全均一，某些区域天然更容易被物理打断、不容易扩增或在测序中产生偏向性，这些都会造成某些区域背景信号异常升高。如果不排除这些区域，软件可能将这种实验噪音误判为转录因子结合或组蛋白修饰的真实信号。

### 2. 请解释 findPeaks 和 findMotifsGenome.pl 主要参数的含义。

- **findPeaks**：
	- `-style`：分析模式，包括`factor`/`histone`模式。
	- `-o`：输出文件路径。
	- `-i`：存储输入样本中间文件的“tag directory”。
	- `-size`：Peak 大小。在此窗口内计算 tag 密度来寻找局部最大值。
	- `-minDist`：峰之间的最小距离，防止在同一个结合位点附近重复找峰。
	- `-fdr`：错误发现率阈值。
	- `gsize`：有效基因组大小。
	- `center`：中心化，分析结束后将峰的位置移动到 tag 堆积密度的最高点。

- **findMotifsGenome.pl**：
	- `-size`：用于分析的区域大小，决定从 Peak 的中心向两边各取多少 bp 的序列进行分析。
	- `len`：Motif 长度，指定需要寻找的基序长度，允许同时输入多个长度。
	- `genome`：参考基因组版本，指定分析所用的基因组。
